ASTRA PROTOCOL ASSISTANT
========================

[PT] Português
--------------
Assistente de consulta rápida para o jogo Astra Protocol 2 (Slice Bar Games).
Ferramenta de fã, não oficial. Os comandos seguem o manual oficial do jogo.

Versões
- standalone: funciona em qualquer Windows 64 bits, sem instalar nada.
- lite: bem menor, mas exige o .NET 8 Runtime instalado:
  https://dotnet.microsoft.com/download/dotnet/8.0

Como usar
- Extraia o .zip inteiro antes de abrir. Rodar o programa de dentro do .zip
  não funciona, porque ele precisa da pasta Data.
- Abra AstraProtocolAssistant.exe.
- Mantenha a pasta Data ao lado do executável.

Teclas
- F1–F6      Telas de referência (as mesmas teclas do jogo)
- Tab        Alterna entre as telas de referência e os procedimentos
- F7         Calculadora de coordenadas (nave + scan = destino)
- F8         Idioma e sobre
- F9/Ctrl+F  Pesquisa livre
- Esc        Volta / sai (pede confirmação)

Observações
- No console clássico do Windows, o Ctrl+F pode abrir a busca do próprio
  console. Nesse caso, use F9.
- O idioma escolhido fica salvo em %APPDATA%\AstraProtocolAssistant.
- Os textos ficam em arquivos .txt na pasta Data e podem ser editados.

[EN] English
------------
Quick reference assistant for the game Astra Protocol 2 (Slice Bar Games).
Unofficial fan tool. Commands follow the game's official manual.

Versions
- standalone: runs on any 64-bit Windows, nothing to install.
- lite: much smaller, but requires the .NET 8 Runtime:
  https://dotnet.microsoft.com/download/dotnet/8.0

How to use
- Extract the whole .zip before opening. Running the program from inside the
  .zip does not work, because it needs the Data folder.
- Open AstraProtocolAssistant.exe.
- Keep the Data folder next to the executable.

Keys
- F1–F6      Reference screens (same keys as the game)
- Tab        Switch between reference screens and procedures
- F7         Coordinate calculator (ship + scan = destination)
- F8         Language and about
- F9/Ctrl+F  Free search
- Esc        Back / exit (asks for confirmation)

Notes
- In the classic Windows console, Ctrl+F may open the console's own search.
  If so, use F9.
- The chosen language is saved in %APPDATA%\AstraProtocolAssistant.
- All texts are .txt files in the Data folder and can be edited.
