# keywords: скан, сканер, датчик, сенсор, обнаруж, найти, поиск, опозна, цель, захват, зонд, планет, сигнал, шум, радар, карта, разведк, сигнал бедствия, маяк
SCIENCE (F3) - Обнаружение и опознавание
Карта дальнего обзора, ближний обзор, форма волны ближайшего сигнала,
счётчик Гейгера, оставшиеся зонды и схема цели.

ГОРЯЧИЕ КЛАВИШИ
F9                            Сканировать цель
F10 / F11                     Приблизить / отдалить

ЦЕЛЬ (только в радиусе сканера ближнего обзора)
TARGET CLOSEST                Ближайшая допустимая цель
TARGET SHIP                   Ближайший корабль
TARGET FIGHTER                Ближайший истребитель (включая союзных)
TARGET STATION                Ближайшая космическая станция
TARGET PLANET                 Ближайшее небесное тело
TARGET ASTEROID               Ближайший космический мусор
TARGET LIFEFORMS              Ближайшая живая биологическая материя
TARGET COLLIDER               Объект, вызвавший сигнал столкновения
TARGET CLEAR                  Сбрасывает цель

СКАНЕРЫ
SCAN                          Сканирует текущую цель
SCAN SPACECRAFT               Корабли поблизости и расстояние до них
ABORT SCAN                    Отменяет активные/ожидающие сканирования
LONG RANGE SCAN               Небесные тела, искусственные сигналы, станции
DISPLAY LONG RANGE SCAN       Последние результаты (относит. координаты)
DISPLAY DETAILS               Научные данные о цели (←/→ страницы)
LAUNCH PROBE                  Запускает зонд (нужен в запасе)
FILTER NOISE                  Фильтрует шум (корабль должен быть стабилен)
ABORT FILTER                  Прекращает фильтрацию
ENABLE RADIO                  Включает сканеры дальнего обзора
DISABLE RADIO                 Выключает сканеры дальнего обзора
SET RADIO <дальность>         Дальность сканеров дальнего обзора

КАРТА
ZOOM IN [%] / ZOOM OUT [%]    Масштаб (по умолчанию 1)
SET ZOOM <%>                  Задаёт масштаб
RECENTRE                      Центрирует карту на корабле

РУЧНОЕ УПРАВЛЕНИЕ (F12, Esc - выход)
↑ ↓ ← →                       Перемещение курсора
Enter                         Захват цели под курсором
+ / -                         Приблизить / отдалить
