OPERATIONS (F6) - Миссия и журналы
Статус миссии, истребители, бортовой журнал и полученные передачи.

ПЕРЕДАЧИ И ИСТРЕБИТЕЛИ
DISPLAY TRANSMISSION          Последняя передача (←/→ страницы)
DISPLAY FIGHTER STATUS [н]    Статус истребителя (без н = все)

БОРТОВОЙ ЖУРНАЛ
LOG [запись]                  Правка записи (без номера = новая)
  F9 правка · F10 отмена · F11 сохранить · F12 прочитать вслух

СИСТЕМА
PAUSE                         Пауза
UNPAUSE / CONTINUE            Продолжить
SAVE                          Сохраняет миссию
LOAD                          Загружает миссию
ALIAS <псевд> / <команда>     Создаёт ярлык (без команды = удаляет)
  напр. ALIAS FULL SHIELDS / SET SHIELDS 100
SAVE ALIASES / LOAD ALIASES   Сохраняет / загружает ярлыки
MANUAL OVERRIDE               Ручное управление экраном (как F12)
SETTINGS                      Настройки (F1-F4 разделы, Esc - выход)
HELP                          Краткий список команд (←/→ страницы)
DISPLAY CREDITS               Титры
SHUTDOWN                      Выключает терминал

КОМАНДНАЯ СТРОКА
Tab                           Автодополнение
↑ / ↓                         История команд
HELM, SCIENCE... + Enter      Ввод имени экрана открывает его
F12                           Ручное управление
Esc                           Выход из подэкрана / ручного управления

РУЧНОЕ УПРАВЛЕНИЕ (F12, Esc - выход)
↑ / ↓                         Перемещение по списку
Tab                           Журнал / передачи
Enter                         Открыть выбранный элемент
