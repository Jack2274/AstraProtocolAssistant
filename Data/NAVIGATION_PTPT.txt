# keywords: navegação, navegar, rota, caminho, trajeto, ponto de passagem, piloto automático, viajar, ir, mapa, coordenadas, salto, saltar, seguir, limitador, limite de velocidade, carta estelar, destino
NAVIGATION (F5) - Navegação e piloto automático
Mapa do setor, vista curta, bússola, estado e rota do piloto automático.

TECLAS
F9                            Liga/desliga o piloto automático
F10 / F11                     Amplia / reduz o mapa

ROTA
PLOT ROUTE <x,y>              Adiciona uma coordenada à rota
PLOT ROUTE TARGET             Adiciona a posição atual do alvo
REMOVE ROUTE [qtd]            Remove o(s) último(s) ponto(s)
CLEAR ROUTE                   Apaga a rota toda

PILOTO AUTOMÁTICO
ENABLE AUTOPILOT              Liga
DISABLE AUTOPILOT             Desliga
SET AUTOPILOT ENGINES <valor>     Ritmo do motor no piloto automático
SET AUTOPILOT THRUSTERS <valor>   Ritmo dos propulsores laterais
SET AUTOPILOT RUDDER <valor>      Ritmo do leme
ENABLE LIMITER                Liga o limitador de velocidade
DISABLE LIMITER               Desliga o limitador
SET LIMITER <velocidade>      Velocidade máxima do piloto automático
FOLLOW [dist1] [dist2]        Segue o alvo (aproxima-se até dist1, para a dist2)
ABORT FOLLOW                  Deixa de seguir

WARP
WARP <x,y>                    Salta para a coordenada (com a nave parada)
ABORT WARP                    Desliga o warp
  Carga enorme no reator; o choque desliga sistemas durante algum tempo.

MAPA
ZOOM IN [%] / ZOOM OUT [%]    Zoom (valor por omissão: 1)
SET ZOOM <%>                  Define o zoom
RECENTRE                      Centra o mapa na nave
DISPLAY STARCHART             Mapa estelar dos pontos descobertos
  Espaço = mostra/oculta nomes    Tab = alterna o objeto destacado

CONTROLO MANUAL (F12, Esc sai)
↑ ↓ ← →                       Move o cursor
Enter                         Adiciona o ponto à rota
Backspace                     Remove o último ponto
+ / -                         Amplia / reduz
