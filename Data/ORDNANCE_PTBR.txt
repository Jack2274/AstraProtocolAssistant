# keywords: armas, armamento, combate, atacar, ataque, lutar, luta, briga, atirar, disparar, tiro, míssil, mísseis, torpedo, laser, mina, contramedida, interferência, caças, drones, defesa, defender, munição, bala
ORDNANCE (F4) - Combate
Escudos, radar de combate, munição (mísseis, minas, chaff), trava de alvo,
lasers, recarga dos tubos e esquema do alvo.

MÍSSEIS
FIRE [ALL]                    Dispara todos os mísseis carregados
FIRE <lado> [ALL | tubo]      Dispara um lado (ou um tubo)
RELOAD [ALL]                  Recarrega todos
RELOAD <lado> [ALL | tubo]    Recarrega um lado (ou um tubo)
UNLOAD [ALL]                  Descarrega todos
UNLOAD <lado> [ALL | tubo]    Descarrega um lado (ou um tubo)
ABORT RELOAD [lado | ALL]     Cancela recargas em andamento
  <lado> = FORWARD | STARBOARD | PORT

LASERS
ENABLE LASERS                 Liga mira e disparo automáticos
DISABLE LASERS                Desliga
SET LASERS <%>                Potência dos lasers
SET LASER MODE <modo>         Prioridade automática:
  ASTEROIDS | CLOSEST | FIGHTERS | LIFEFORMS | MISSILES | TARGET

CONTRAMEDIDAS
DROP CHAFF                    Lança chaff (contramedida eletromagnética)
DROP MINE                     Larga uma mina
LAUNCH EMP [fuse]             Pulso EMP (fuse padrão 3 s)
ENABLE SIGNAL JAMMERS         Bloqueia sinais do alvo (exige alvo)
DISABLE SIGNAL JAMMERS        Desliga o bloqueio

CAÇAS (drones IA)
LAUNCH FIGHTERS [baia]        Lança caças (sem baia = todos)
RECALL FIGHTERS [caça]        Recolhe caças (sem número = todos)
SET FIGHTER MODE <modo> [caça]
  CLOSEST | FIGHTERS | SHIPS | TARGET | IDLE (segue a nave, não ataca)

ESCUDOS
SET SHIELDS [face] <%>        FORWARD | STARBOARD | PORT | AFT

CONTROLE MANUAL (F12, Esc sai)
Num 0                         Liga/desliga lasers
Num 7 / 4 / 1                 Míssil de bombordo 1 / 2 / 3
Num 9 / 6 / 3                 Míssil de estibordo 1 / 2 / 3
Num 8 / 5                     Míssil frontal 1 / 2
