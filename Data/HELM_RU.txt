HELM (F1) - Пилотирование корабля
Ближний обзор, двигатели, маневровые, руль, скорость, координаты и компас.
При двигателях на 0 корабль летит по инерции, пока его не стабилизировать.

ДВИГАТЕЛИ
SET ENGINES <%>               Главные двигатели, вперёд/назад (минус = назад)
SET THRUSTERS <%>             Боковые двигатели (+ правый борт / - левый)
SET RUDDER <%>                Вращение (+ по часовой / - против часовой)
SET BEARING <угол>            Поворачивает корабль на заданный курс

СТАБИЛИЗАЦИЯ
STABILIZE [ALL]               Останавливает движение и вращение
STABILIZE POSITION            Останавливает только движение
STABILIZE ROTATION            Останавливает только вращение

СТЫКОВКА
DISPLAY DOCKING HUD           Открывает HUD стыковки (только HELM)
DATA LINK                     Связь с целью (обе стороны должны принять)
ABORT LINK                    Отменяет канал данных
REQUEST DOCK                  Запрос стыковки (нужен DATA LINK)
REQUEST DRYDOCK               Запрос ремонта (нужен DATA LINK)
REQUEST RESUPPLY              Запрос снабжения (нужен DATA LINK)
UMBILICAL ANGLE <борт> <угол>     Угол рукава (рукав должен быть убран)
UMBILICAL EXTEND <борт>       Выдвигает рукав
UMBILICAL LOCK <борт>         Стыкует рукав со шлюзом цели
UMBILICAL UNLOCK <борт>       Отстыковывает (сделайте до втягивания!)
UMBILICAL RETRACT <борт>      Втягивает рукав
UMBILICAL STOP <борт>         Останавливает выдвижение/втягивание
OPEN AIRLOCK <борт>           Открывает шлюз (риск для жизнеобеспечения)
CLOSE AIRLOCK <борт>          Закрывает шлюз
  <борт> = STARBOARD | PORT

РУЧНОЕ УПРАВЛЕНИЕ (F12, Esc - выход)
+ / -                         Увеличить / уменьшить тягу главных двигателей
← / →                         Вращение против / по часовой стрелке
