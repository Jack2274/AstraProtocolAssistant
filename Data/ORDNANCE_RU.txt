# keywords: оружие, бой, атак, сражен, стрел, огонь, ракет, торпед, лазер, мин, диполь, отражател, эми, глушил, помех, истребител, дрон, защит, оборон, боезапас, патрон
ORDNANCE (F4) - Бой
Щиты, боевой радар, боезапас (ракеты, мины, дипольные отражатели), захват
цели, лазеры, перезарядка торпедных аппаратов и схема цели.

РАКЕТЫ
FIRE [ALL]                    Пуск всех заряженных ракет
FIRE <борт> [ALL | аппарат]   Пуск с одного борта (или из одного аппарата)
RELOAD [ALL]                  Перезаряжает все
RELOAD <борт> [ALL | аппарат] Перезаряжает один борт (или один аппарат)
UNLOAD [ALL]                  Разряжает все
UNLOAD <борт> [ALL | аппарат] Разряжает один борт (или один аппарат)
ABORT RELOAD [борт | ALL]     Отменяет текущие перезарядки
  <борт> = FORWARD | STARBOARD | PORT

ЛАЗЕРЫ
ENABLE LASERS                 Включает автоприцеливание и автоогонь
DISABLE LASERS                Выключает
SET LASERS <%>                Мощность лазеров
SET LASER MODE <режим>        Приоритет автоприцеливания:
  ASTEROIDS | CLOSEST | FIGHTERS | LIFEFORMS | MISSILES | TARGET

КОНТРМЕРЫ
DROP CHAFF                    Сбрасывает диполи (электромагнитная помеха)
DROP MINE                     Сбрасывает мину
LAUNCH EMP [запал]            Импульс ЭМИ (запал по умолчанию 3 с)
ENABLE SIGNAL JAMMERS         Глушит сигналы цели (нужна цель)
DISABLE SIGNAL JAMMERS        Прекращает глушение

ИСТРЕБИТЕЛИ (дроны с ИИ)
LAUNCH FIGHTERS [отсек]       Выпускает истребители (без отсека = все)
RECALL FIGHTERS [истребитель] Отзывает истребители (без номера = все)
SET FIGHTER MODE <режим> [истребитель]
  CLOSEST | FIGHTERS | SHIPS | TARGET | IDLE (следует за кораблём, без атаки)

ЩИТЫ
SET SHIELDS [щит] <%>         FORWARD | STARBOARD | PORT | AFT

РУЧНОЕ УПРАВЛЕНИЕ (F12, Esc - выход)
Num 0                         Вкл/выкл лазеры
Num 7 / 4 / 1                 Левая ракета 1 / 2 / 3
Num 9 / 6 / 3                 Правая ракета 1 / 2 / 3
Num 8 / 5                     Носовая ракета 1 / 2
