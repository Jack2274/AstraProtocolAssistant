УГРОЗА СТОЛКНОВЕНИЯ
Реагируйте на сигнал об угрозе столкновения.

ШАГИ
1. TARGET COLLIDER            Захват источника тревоги
2. SCAN                       Опознать объект (астероид, корабль...)
3. SET THRUSTERS 100          Уклон вбок (или -100 в другую сторону)
4. SET SHIELDS FORWARD 100    Усиливает угрожаемую сторону
5. SET LASER MODE TARGET      (если астероид) Лазеры бьют цель
6. ENABLE LASERS              Огонь по объекту
7. STABILIZE ALL              Остановка после ухода с курса столкновения

ВНИМАНИЕ
- Не начинайте со STABILIZE: остановка не уводит корабль с пути.
- Ручное управление (F12) в HELM без бокового хода: используйте SET THRUSTERS.
- Укажите сторону (FORWARD, STARBOARD, PORT, AFT), откуда идёт объект;
  её показывает боевой радар в ORDNANCE (F4).
