DEFESA CONTRA MÍSSEIS
Reage a mísseis que se aproximam.

PASSOS
1. ENABLE LASERS              Disparo laser automático
2. SET LASER MODE MISSILES    Os lasers visam o projétil mais próximo
3. DROP CHAFF                 Contramedidas eletromagnéticas
4. SET SHIELDS AFT 100        Reforça a face ameaçada

ATENÇÃO
- Faces: FORWARD, STARBOARD, PORT ou AFT. Use o radar de combate
  no ORDNANCE (F4) para ver de onde vem a ameaça.
- O chaff requer cargas em stock.
