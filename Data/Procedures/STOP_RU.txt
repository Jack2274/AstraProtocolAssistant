# keywords: останов, стоп, тормоз, затормозить, замереть, неподвиж, стабилиз, инерц, сбросить скорость, на месте, остановиться
ОСТАНОВКА КОРАБЛЯ
Полностью остановите корабль. При двигателях на 0 корабль продолжает
двигаться (инерция): его нужно стабилизировать.

ШАГИ
1. DISABLE AUTOPILOT          Автопилот может перебивать ручные команды
2. SET ENGINES 0              Выключает главные двигатели
3. SET THRUSTERS 0            Выключает боковые двигатели
4. SET RUDDER 0               Останавливает вращение
5. STABILIZE ALL              Останавливает движение и вращение

ВНИМАНИЕ
- STABILIZE POSITION или STABILIZE ROTATION гасят только одно из двух.
- Включение автопилота без маршрута тоже стабилизирует корабль.
