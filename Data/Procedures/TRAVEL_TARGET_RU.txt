ПОЛЁТ К ЦЕЛИ
Ведите корабль к объекту с помощью автопилота.

ПЕРЕД НАЧАЛОМ
- Цель должна быть в радиусе сканера ближнего обзора.

ШАГИ
1. TARGET STATION             Захват цели (или SHIP, PLANET, CLOSEST...)
2. PLOT ROUTE TARGET          Добавляет позицию цели в маршрут
3. SET LIMITER 500            (необяз.) Максимальная скорость автопилота
4. ENABLE LIMITER             (необяз.) Включает ограничитель скорости
5. ENABLE AUTOPILOT           Начать полёт (или F9 в NAVIGATION)

ВНИМАНИЕ
- Автопилот не управляет реактором: следите за ENGINEERING (F2).
- PLOT ROUTE TARGET запоминает позицию один раз. Для движущейся цели
  используйте FOLLOW <dist1> <dist2> при включённом автопилоте.
