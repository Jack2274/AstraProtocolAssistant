# keywords: навигац, маршрут, путь, точк, автопилот, полёт, лететь, карта, координат, варп, прыжок, следова, ограничител, лимит скорости, звёздная карта, сектор
NAVIGATION (F5) - Навигация и автопилот
Карта сектора, ближний обзор, компас, состояние автопилота и маршрут.

ГОРЯЧИЕ КЛАВИШИ
F9                            Вкл/выкл автопилот
F10 / F11                     Приблизить / отдалить

МАРШРУТ
PLOT ROUTE <x,y>              Добавляет координату в маршрут
PLOT ROUTE TARGET             Добавляет текущую позицию цели
REMOVE ROUTE [кол-во]         Удаляет последнюю точку (точки)
CLEAR ROUTE                   Очищает весь маршрут

АВТОПИЛОТ
ENABLE AUTOPILOT              Включает
DISABLE AUTOPILOT             Выключает
SET AUTOPILOT ENGINES <знач>      Тяга двигателей на автопилоте
SET AUTOPILOT THRUSTERS <знач>    Тяга маневровых
SET AUTOPILOT RUDDER <знач>       Скорость руля
ENABLE LIMITER                Включает ограничитель скорости
DISABLE LIMITER               Выключает ограничитель
SET LIMITER <скорость>        Максимальная скорость автопилота
FOLLOW [дист1] [дист2]        Следовать за целью (до дист1, стоп на дист2)
ABORT FOLLOW                  Прекращает следование

WARP
WARP <x,y>                    Варп к координате (корабль неподвижен)
ABORT WARP                    Отключает варп-двигатель
  Огромная нагрузка на реактор; удар на время отключает системы.

КАРТА
ZOOM IN [%] / ZOOM OUT [%]    Масштаб (по умолчанию 1)
SET ZOOM <%>                  Задаёт масштаб
RECENTRE                      Центрирует карту на корабле
DISPLAY STARCHART             Звёздная карта открытых точек
  Space = показ названий   Tab = следующий выделенный объект

РУЧНОЕ УПРАВЛЕНИЕ (F12, Esc - выход)
↑ ↓ ← →                       Перемещение курсора
Enter                         Добавить точку в маршрут
Backspace                     Удалить последнюю точку
+ / -                         Приблизить / отдалить
